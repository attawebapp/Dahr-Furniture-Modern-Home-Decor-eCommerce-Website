# Dahr Furniture – Modern Home Decor eCommerce Website

## Overview

Dahr Furniture is a responsive home furniture and interior decor website developed with HTML, CSS, Bootstrap, JavaScript, and PHP. The website presents stylish furniture collections, category pages, featured products, customer testimonials, and a clean shopping experience.
